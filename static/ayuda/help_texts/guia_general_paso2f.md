### Guía para la Planilla 2F: Posturas Forzadas

Evalúa el riesgo de posturas incómodas o forzadas. Se basa en la **observación directa.**

* **PASO 1:**
    > Verifica si se adoptan posturas forzadas de forma **habitual** (no ocasional) [1298]. Si la respuesta es "NO", el riesgo es tolerable.
* **PASO 2:**
    > Es una lista de chequeo para identificar qué parte del cuerpo adopta una postura forzada (cuello, brazos, muñecas, cintura o miembros inferiores) [1302].
* **Resultado:**
    > Si se marca "SI" en alguna de las posturas, se debe realizar una Evaluación de Riesgos completa, usando métodos como **RULA o REBA** [1304, 1305].
